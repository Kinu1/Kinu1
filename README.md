# Pedro Loubach

**Desenvolvedor Full Stack | React · TypeScript · C#/.NET · Node.js/NestJS**

Desenvolvo funcionalidades completas para aplicações web: interfaces para operar o sistema, APIs para aplicar regras de negócio e bancos relacionais para persistir os dados. Minha experiência inclui sistemas de gestão, e-commerce e integração de pagamentos, com atenção à validação das informações, às permissões de acesso e ao tratamento de erros.

## Sobre mim

- Construção de interfaces com React e TypeScript, formulários com validação, gerenciamento de estado e comunicação com APIs.
- Desenvolvimento de APIs em ASP.NET Core e NestJS, com autenticação JWT, autorização por perfil, modelagem relacional e documentação Swagger/OpenAPI.
- Implementação de testes automatizados e configuração de ambientes locais com Docker e verificações com GitHub Actions.
- Integração com Mercado Pago no LigaHub, com pagamentos Pix e cartão validados em sandbox.
